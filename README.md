# 书画室本地看板系统

[![tests](https://github.com/LeoWinston-9596/calligraphy-studio-dashboard/actions/workflows/tests.yml/badge.svg)](https://github.com/LeoWinston-9596/calligraphy-studio-dashboard/actions/workflows/tests.yml)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**简体中文** · [English](README.en.md)

> **为什么做** —— 书画室老师用手机记学员作品和课时，教务 App 导出的 Excel 没人看得懂；
> 更麻烦的是老师上了课不销课，系统里的"剩余课时"一直偏高，续费提醒等于失灵。
>
> **最难的地方** —— 手机浏览器**不给非受信任 HTTPS 页面麦克风权限**。点"继续访问"没用，
> `navigator.mediaDevices` 根本不存在。所以要自签证书、引导用户装成系统根证书，
> 而 iOS 走 `.mobileconfig` 描述文件、必须用 Safari，Android 完全是另一套路径。
> Apple 还额外要求证书有效期 ≤825 天且带 `serverAuth` 扩展，否则装了也不认。
>
> **重来会改什么** —— 用户体系当时按单店设计，多店需要重构；跟进人一开始做成了单值字段，
> 后来发现一个学员在不同班跟不同老师，只能加一张表重做，早点问清楚就不用返工。

把教务 App 导出的 Excel 变成可查询的看板，并支持老师用手机上传学员作品与语音/文字评价。
**纯局域网运行，零公网依赖**，拔掉外网线一切功能照常。

## 一、启动（macOS / Windows 通用）

| 系统 | 操作 |
|------|------|
| macOS | 双击 **`启动.command`** |
| Windows | 双击 **`启动.bat`** |
| 任意系统（命令行） | `python run.py` |

首次启动会自动完成三件事：创建虚拟环境 `.venv` → 安装依赖 → 构建前端。
之后每次启动只需几秒。

> 前置条件：装有 **Python 3.11 及以上**。
> 前端 `web/dist` 已随包提供，因此**没有 Node.js 也能正常启动**；
> 只有你要改前端源码时才需要 Node。

启动后终端会打印访问地址：

```
电脑访问   http://192.168.x.x:8000
手机访问   https://192.168.x.x:8443   ← 录音需用这个
初始账号   admin / admin123（首次登录强制改密）
```

停止服务：在终端窗口按 `Ctrl + C`。

### 手机要能录音，必须做两件事

**① 用 `https://…:8443` 打开**（HTTP 下浏览器一律禁止麦克风）。
如果开的是 `http://…:8000`，页面顶部有蓝色提示，点一下就跳到 HTTPS 的同一页面。

**② 把证书装成手机信任的根证书。**

这一步最容易被忽略：**光点"继续访问"是不够的**。iOS Safari 和 Android Chrome 的规则是——
只要证书不被系统信任，就**根本不把麦克风 API 交给页面**。此时地址栏明明是 https，
但页面拿不到 `navigator.mediaDevices`，录音按钮依然出不来。

手机浏览器打开 **`https://…:8443/cert/help`**，按页面上的步骤装一次即可（iOS / Android 都有）。
系统设置页里也有入口："设置 → 手机录音设置 → 证书安装说明"。

**iPhone 必须用 Safari 打开这个页面。** 微信内置浏览器、Chrome 都装不了描述文件——
页面会自动识别并提示你换 Safari。iPhone 走的是 `.mobileconfig` 描述文件，
点"下载描述文件"后 Safari 会弹"此网站正尝试下载一个配置描述文件"，选允许。

> iPhone 有两个坑，漏一个都白装：
> 1. 下载后**不会自动安装**，要去 `设置` App 顶部点"已下载描述文件"手动装
>    （或 `设置 → 通用 → VPN与设备管理`）。
> 2. 装完还要去 `设置 → 通用 → 关于本机 → 证书信任设置`，
>    **把"书画室看板"的开关打开**。

不装也能用——录音控件会自动变成**上传音频文件**（老师用"语音备忘录"录好再选文件），
拍照和文字评价完全不受影响。

设置页里有一块「手机录音设置」，直接显示当前手机的安全上下文、麦克风 API、录音 API 是否可用，
出问题时截图就能定位。

> 建议让老师把 `https://…:8443` 存成手机书签，以后直接点书签进。

## 二、日常使用流程

1. **导入数据**（更多 → 数据导入）：把教务导出的 4 个 Excel 拖进去，
   预览前 5 行确认无误后点"确认导入"。系统按列名自动识别文件类型。
2. **老师上传作品**（工作台）：我的班级 → 点班级 → 点学员 → 拍照 → 录音/文字 → 提交。
3. **查数据**：学员看板搜学员、看课时与作品时间轴；提醒看板盯续费/到期/缺课。

### 四种支持的 Excel

| 文件 | 去向 | 说明 |
|------|------|------|
| 在读学员名单 `.xls` | 学员档案 | 以 `学号` 为主键，学号缺失时用 `姓名+手机号` |
| 学生报读课程 `.xls` | 课时账户（核心） | 只读 `报读课程` sheet；同时建立"班级 → 课程"映射 |
| 订单导出 `.xlsx` | 订单（只读） | |
| 收支明细 `.xls` | 收支（只读） | |

导入是**整表覆盖式更新**：同类型数据以本次导入为准，所以**重复导入同一个文件不会产生重复数据**。
导入覆盖**不算编辑**，不会产生编辑角标。

## 三、剩余课时的两种口径

教务系统的"剩余数量"只在导入那一刻是准的，之后老师上了课但没销课，数字就偏大。
所以系统提供两种口径，在**设置页**一键切换（默认估算口径）：

- **导入口径**：直接显示 Excel 里的 `剩余数量`。
- **估算口径**：`导入剩余 − 导入之后的评价课次数`。
  同一学员、同一课程、**同一天的多条评价只算 1 课次**；把某天的评价全删掉，余额会自动退回。

界面显示成 `约 N 课时`，点一下能看到算式，例如：

```
导入时 7（8月1日） − 评价 2 次 = 约 5
```

提醒看板的阈值判断跟随当前口径。

**偏差报告**：每次导入报读课程后，系统自动对比"上期估算剩余 vs 本期导入剩余"，
把差值不为 0 的学员列成一张表（可在数据导入页随时回看）。
它只做提示，**不会自动修改任何数据**。

## 四、编辑留痕

学员信息、作品评价、跟进状态、评语模板——**任何编辑都会留痕**。

卡片右上角会出现橙色角标：

| 编辑次数 | 角标 |
|---------|------|
| 0 | 不显示 |
| 1 | 已编辑 |
| 2 | 已二次编辑 |
| ≥3 | 已多次编辑 |

点角标可以看到完整记录：谁、什么时候、改了哪个字段、改前 → 改后。
删除作品是**软删除**，时间轴不再显示，但编辑记录里查得到，估算余额也会相应退回。

## 五、语音转文字（可选）

老师录的语音评价可以自动转成文字。**这是可选功能，不装也不影响任何既有功能**，
只是语音评价没有文字稿。

### 装一次

```bash
python install_asr.py      # 约 230MB，只有这一步需要联网
```

装完重启服务。之后新上传的语音会自动转写；旧录音在「设置 → 语音转文字」里点
「全部重新转写」补上。

引擎是 **SenseVoice-Small**（sherpa-onnx 跑 ONNX，纯 CPU，不装 PyTorch），
转写全程离线，实测 **CPU 上 40× 实时**——60 秒录音约 1.5 秒转完。
转写在后台异步跑，**老师点提交立刻返回**，不会拖慢上传流程。

### 为什么有个"术语表"

语音识别把专业词写成同音字是通病，实测就有：

| 原话 | 识别成 |
|---|---|
| 提按 | 提案 |
| 皴法 | 村法 |
| 藏锋 | 藏风 |

所以转写完会按术语表做一次同音纠正。内置了 56 个书画常用词，
教务可以在「设置 → 语音转文字」里增删，页面上还能**粘一句话试试会被纠成什么**。

补完术语表后点「全部重新转写」，之前转错的会按新表重跑。
**老师人工校对过的不会被覆盖。**

### 老师可以改

时间轴里每条语音下面都有文字稿，点「校对文字稿」可以改。改过的会标成
「已人工校对」，并且**照样走编辑留痕**（谁改的、改前改后都能查）。

导出作品集时文字稿会一起打印出来——以前打印版只有个音频链接，等于丢失了语音内容。

## 六、打包成安装程序（给别人用）

对方电脑**不需要装 Python、不需要联网**，双击安装即可。

### 在 Windows 上打包（出安装程序 exe）

把整个项目文件夹拷到一台 Windows 电脑上，**双击 `打包.bat`**。
它会自动装依赖、下语音模型、打包，最后在 `installer_output\` 生成
`书画室看板-安装程序.exe` —— 这一个文件发给对方就行。

> 想要"一个安装文件"必须装 [Inno Setup](https://jrsoftware.org/isdl.php)（免费）。
> 没装也能用：脚本会生成 `dist\书画室看板\` 文件夹，打个 zip 发过去，
> 对方解压后双击里面的 `书画室看板.exe` 一样能跑。

**exe 只能在 Windows 上生成**，PyInstaller 不支持跨平台编译——在 Mac 上打不出 exe。

### 在 macOS 上打包

```bash
python build.py
```

产物在 `dist/书画室看板/`，整个文件夹拷给对方，双击里面的 `书画室看板` 启动。

### 打出来是什么样

- 体积约 **425MB**（含 Python 运行时、全部依赖、前端、228MB 语音模型）
- 首次启动约 **30 秒**（系统要扫描大文件），之后正常
- 启动后**自动打开浏览器**，窗口里显示局域网地址给手机用
- 不小心双击第二次会提示"已经在运行了"，不会崩

### 数据放在哪（重要）

数据在**程序目录下的 `data` 文件夹**，不在 C 盘用户目录，也不在临时目录。

- 换电脑：把整个程序文件夹拷过去，数据一起走
- 卸载：**不会删掉 data**，学员资料还在
- 重装前建议先把 `data` 和 `backups` 拷出来存一份

> 这一点专门写了测试盯着（`tests/test_packaging.py`）：打包程序如果把数据库写进
> 临时解压目录，用户每次重启都会发现数据没了——这是打包最常见的事故。

## 七、国内网络环境说明

**日常使用完全不需要联网。** 系统跑起来之后零公网依赖，拔掉外网线一切照常。
只有三个「装东西」的步骤会联网，都已经配好国内镜像：

| 步骤 | 默认源 | 国内自动回退 |
|---|---|---|
| 装 Python 依赖 | PyPI | 清华 TUNA → 阿里云 |
| 装语音模型 | hf-mirror.com（国内镜像） | ModelScope → HuggingFace → GitHub |
| 构建前端（一般用不到） | npmjs | npmmirror（淘宝） |

都是**失败自动换源**，不用你手动配。想指定的话：

```bash
SBS_PIP_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple python run.py
python install_asr.py --source modelscope
```

### 语音模型的下载

默认走 **hf-mirror.com**，直接下 228MB 的 int8 模型。
（原来走 GitHub Releases 要下 999MB 整包，里面 937MB 的 fp32 模型我们根本不用，
国内还基本下不动。现在下载量只有原来的四分之一。）

看有哪些源：`python install_asr.py --list`

### 一台机器都连不上外网怎么办

在能上网的机器上下好，拷过去：

1. 打开 https://hf-mirror.com/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/tree/main
2. 下载 `model.int8.onnx` 和 `tokens.txt`
3. 放进 `data/models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/`
4. 重启服务

**打包成安装程序后连这一步都省了**——模型已经打进安装包，
目标电脑全程不需要联网。

## 十一、账号与班级归属

### 角色分级（只管账号，不管数据）

| | 新增账号 | 停用/启用 | 可创建的角色 |
|---|---|---|---|
| **校长** | ✅ | 教务、老师 | 校长 / 教务 / 老师 |
| **教务** | ✅ | 老师 | 教务 / 老师 |
| **老师** | ❌ | ❌ | — |

规则是「只能创建同级与下级，只能停用严格下级」，任何人都不能停用自己。

> **业务数据不受角色限制**：学员、课时、作品、评价、导入、订单收支，
> 所有登录用户依然都能看、都能改——靠编辑留痕（§编辑留痕）保证可追溯，而不是权限墙。
> 分级只加在「用户管理」这一块。

### 跟进人：按班级记，可多选

一个学员会报多个班，每个班可能是不同老师带的。所以跟进人**记在"学员 + 班级"上**，
不是记在学员身上：学员详情页有一张「班级与跟进人」卡，每个班一行，点"修改跟进人"可以**多选**。
学员基本信息里的"跟进人"是这些班的**汇总**（只读）。

> 教务 App 导出的表里每个学员只有一个跟进人（`学管师`列还是空的），
> 所以多老师关系只能在这里维护。

**重新导入不会冲掉你手工加的老师。** 系统给导入值留了一个独立"槽位"：
再次导入时只替换上次导入的那个值，你手工加的老师原样保留。举例：

| 操作 | 结果 |
|---|---|
| 导入（跟进人=李老师） | `李老师` |
| 手工加上王老师 | `李老师、王老师` |
| 原样重新导入 | `李老师、王老师`（没变） |
| 教务 App 改成赵老师后导入 | `赵老师、王老师`（李老师被替换，王老师留着） |

改跟进人算编辑，会在学员卡上出角标，点开能看到"谁在哪个班把谁改成了谁"。

### 老师的班级：跟着跟进人自动走

系统按跟进人算出每位老师负责哪些班。**给某个班加一个跟进人，那个班立刻归属于他**——
包括你手工加的。

创建老师账号时，填完姓名会**自动勾中**导入表里对应的老师身份并带出全部班级，
不用一个一个手选。一个账号可以勾**多个身份**（比如同一个人在表里既叫"张老师"又叫别的名字），
班级取并集。候选列表会显示"张老师（12 班 · 30 人）"方便确认。

账号有两种班级归属模式：

- **自动跟随导入表格**（默认，推荐）：以后你在教务 App 新开了班，
  只要跟进人还是这位老师，**导入之后班级会自动出现在他的"我的班级"里**，不用回来补选。
- **手动勾选**：固定几个班，新班不会自动进来。

姓名对不上时（比如账号叫"张三"、表里写的是"张老师"），系统会做模糊匹配，
匹配结果会显示出来，不对可以手动改。
